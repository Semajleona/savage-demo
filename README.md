

Project Overview

Savage Demo is a full-stack message board application built to practice the fundamentals of CRUD (Create, Read, Update, Delete) operations.

The application allows users to create messages, view saved messages, increase or decrease a message's score using thumbs-up and thumbs-down buttons, and delete messages.

This project is a great introduction to full-stack development because it demonstrates how the frontend, backend, and database communicate to create an interactive web application.

The project is based on the original Savage Demo by Leon Noel, with additional thumbs-down functionality.

Tech Stack

Frontend

HTML5 — Structures the message board and forms.

CSS3 — Styles the application.

JavaScript — Handles user interactions and button clicks.

EJS — Dynamically displays messages retrieved from MongoDB.

Font Awesome — Provides thumbs-up, thumbs-down, and delete icons.

Backend

Node.js — Runs JavaScript on the server.

Express.js — Handles routes and HTTP requests.

Body-parser — Processes form submissions and JSON data.

Database

MongoDB — Stores messages and their scores.

MongoDB Node.js Driver — Connects the Express server to MongoDB.
