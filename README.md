# Savage Demo — CRUD Message Board

## 📖 Description

A full-stack message board application that allows users to create, view, update, and delete messages. Users can also increase or decrease message scores using thumbs-up and thumbs-down buttons. This project demonstrates CRUD operations and how the frontend, backend, and database work together.

## ✨ Project Features

- Create and post messages.
- Display messages stored in MongoDB.
- Increase message scores using thumbs-up buttons.
- Decrease message scores using thumbs-down buttons.
- Delete messages from the message board.
- Dynamically update message content using JavaScript and EJS.

## 🛠️ Tech Stack

- **HTML5** — Structures the webpage.
- **CSS3** — Styles the application.
- **JavaScript** — Handles user interactions.
- **EJS** — Dynamically displays messages.
- **Node.js & Express.js** — Handles backend routes and requests.
- **MongoDB** — Stores messages and scores.
- **MongoDB Node.js Driver** — Connects the server to the database.
- **Body-parser** — Processes incoming request data.
- **Font Awesome** — Provides interactive icons.

## 🧠 What I Learned

- How to build a full-stack application using Node.js and Express.js.
- How to perform CRUD operations with MongoDB.
- How to use EJS to display database information.
- How to handle user interactions with JavaScript.
- How to update and delete database records.
- How frontend and backend components communicate.

## 💻 How to Install

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project folder:
   ```bash
   cd <repository-folder>
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Configure your MongoDB connection.
5. Start the server using the command specified in `package.json`.
6. Open the local application URL in your browser.
